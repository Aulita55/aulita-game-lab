# Тренировка ума

Раздел Игровой вселенной АюлитА: 50 оригинальных игр и 4 уже готовые игры сайта в семи категориях. Статика без сборки, работает на компьютере и телефоне.

- `core/engine.js` — раунд: таймер, очки, адаптивная сложность, звук.
- `core/catalog.js` — список игр. Новая игра = строка здесь + функция в `games/<категория>.js`.
- Котики и лапка взяты из брендбука (Aulita_Brandbook): все полностью одеты, младшего сына зовут Тим.
- `core/art.js` — все картинки в едином стиле. Символ в тексте игры сам становится картинкой, поэтому эмодзи на экране не появляются.
- `core/fish.js` — рыбки и аквариум.
- `core/store.js` — прогресс в браузере. **При переносе в платформу заменяется на запросы к серверу.**
- `core/app.js` — страницы раздела. При переносе заменяется на страницы платформы.
- `games/*.js` — игры. Получают только `ctx`, от сайта не зависят и переносятся без изменений.
- `home-entry.js` — блок на главной, добавляется поверх готовой сборки.
