# Озвучка английского

Готовые записи созданы для «Тетради» синтетическим женским британским голосом bf_emma, Kokoro-82M v1.0, темп 0.82. Это ИИ-озвучка, не запись преподавателя. Модель и голос: https://huggingface.co/hexgrad/Kokoro-82M (Apache-2.0); ONNX-экспорт: https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0 . Файлы модели и ключи в сайт не включены.

Для 131 глагола использованы заданные IPA всех трёх форм из `../verb-pronunciations.tsv`. Отдельные записи форм различаются по ID, даже если написания совпадают. В примерах Past Simple целевая форма также задаётся фонетически. Все фактические входные фонемы записаны в `sources.json`. Результат проверен по наличию сигнала, декодированию, длительности и границам фраз; это не заявление о проверке акцента ребёнка.

1 791 запись и 131 набор форм находятся в локальных MP3-пакетах, `manifest.js` задаёт интервалы. Файлы CBR 48 kbit/s, mono 24 kHz. Плеер прекращает запись до соседнего фрагмента, отменяет звук при переключении/скрытии страницы и перед микрофоном. Сайт не обращается к службе синтеза; для будущих неизвестных фраз учителя явно обозначается голос устройства. В упражнениях с неправильными глаголами догадка браузера не используется.

Повторная генерация (из корня репозитория; `kokoro-onnx==0.6.1`, `soundfile==0.14.0`, ffmpeg):

```sh
node games/english-notebook/tools/build-voice-corpus.cjs /tmp/corpus.json
python games/english-notebook/tools/offline-run.py games/english-notebook/tools/generate-voice.py /tmp/corpus.json /path/kokoro-v1.0.onnx /path/voices-v1.0.bin /path/local-cache games/english-notebook/audio
```

Запуск должен оставаться офлайн: сетевые syscalls процесса запрещены seccomp, телеметрия ONNX Runtime дополнительно отключена. Если офлайн-фильтр недоступен, генератор не следует запускать без него. Синтез использует только явно заданные локальные файлы модели; сборщик не загружает модель автоматически.
